# Infobip Documentation

> Infobip is a global cloud communications platform. Send messages via SMS, Email, WhatsApp, RCS, Viber, Voice, and 16+ channels through unified APIs. Build AI agents with MCP servers. Manage customer data, automate engagement, and run contact centers.

Infobip provides two primary integration paths: REST APIs for direct channel integration, and MCP (Model Context Protocol) servers for AI agent integration. For omnichannel messaging, prefer the Messages API which unifies all channels under a single endpoint. Each API product also has a dedicated per-channel API for channel-specific features. All API requests require authentication via API key (recommended) or OAuth 2.0, sent in the Authorization header as `App YOUR_API_KEY`. Each Infobip account has a personalized base URL in the format `{yoursubdomain}.api.infobip.com`.

## Create an Account

Sign up for a free Infobip account at [infobip.com/signup](https://www.infobip.com/signup) — no credit card required. After signing up:

1. **Get your API key** from the Infobip portal. Go to Account Settings → API Keys and create a key with the `sms:message:send` scope. See [API Authentication](https://www.infobip.com/docs/essentials/api-essentials/api-authentication) for details.
2. **Find your base URL** in the portal — it looks like `{yoursubdomain}.api.infobip.com`. See [Base URL](https://www.infobip.com/docs/essentials/api-essentials/base-url).

For the full onboarding walkthrough, see [Create an Account](https://www.infobip.com/docs/essentials/getting-started/create-an-account).

## Send Your First Message

With your API key and base URL, send an SMS with a single REST call:

```shell
curl -X POST https://{yoursubdomain}.api.infobip.com/sms/3/messages \
  -H 'Authorization: App {YOUR_API_KEY}' \
  -H 'Content-Type: application/json' \
  -d '{
    "messages": [
      {
        "sender": "ServiceSMS",
        "destinations": [{ "to": "YOUR_PHONE_NUMBER" }],
        "content": { "text": "Hello from Infobip!" }
      }
    ]
  }'
```

During the free trial, use `ServiceSMS` as the sender and send to the phone number you verified at signup (up to 5 verified numbers). For full details, see [Start Sending Messages](https://www.infobip.com/docs/essentials/getting-started/start-sending-messages).

The same pattern works across all channels — swap the endpoint and payload for [WhatsApp](https://www.infobip.com/docs/api/channels/whatsapp), [Email](https://www.infobip.com/docs/api/channels/email), [RCS](https://www.infobip.com/docs/api/channels/rcs), [Viber](https://www.infobip.com/docs/api/channels/viber), and more. For omnichannel sending from a single endpoint, use the [Messages API](https://www.infobip.com/docs/api/platform/messages-api).

## Browsing Infobip Documentation with AI

The preferred way to explore Infobip documentation using AI tools is the Infobip Docs Search MCP server at `https://mcp.infobip.com/search`. This is a remote MCP server that provides semantic search across the entire Infobip documentation hub -- no API key required. AI tools like Claude Code, Cursor, Windsurf, and any MCP-compatible client can connect to it and search all product docs, tutorials, API guides, and use cases.

To connect, pick the setup that matches your tool:

Claude Code:
```
claude mcp add --transport http infobip-docs https://mcp.infobip.com/search
```

OpenAI Codex CLI:
```
codex --full-auto --mcp-server "https://mcp.infobip.com/search"
```

Cursor (add to `.cursor/mcp.json`):
```json
{
  "mcpServers": {
    "infobip-docs": {
      "url": "https://mcp.infobip.com/search"
    }
  }
}
```

Windsurf (add to `~/.codeium/windsurf/mcp_config.json`):
```json
{
  "mcpServers": {
    "infobip-docs": {
      "serverUrl": "https://mcp.infobip.com/search"
    }
  }
}
```

VS Code / GitHub Copilot (add to `.vscode/mcp.json`):
```json
{
  "servers": {
    "infobip-docs": {
      "type": "http",
      "url": "https://mcp.infobip.com/search"
    }
  }
}
```

JetBrains IDEs (Settings > Tools > AI Assistant > MCP Servers > Add):
```json
{
  "mcpServers": {
    "infobip-docs": {
      "type": "http",
      "url": "https://mcp.infobip.com/search"
    }
  }
}
```

Claude Desktop or any STDIO-only client (via mcp-remote bridge):
```json
{
  "mcpServers": {
    "infobip-docs": {
      "command": "npx",
      "args": ["mcp-remote", "https://mcp.infobip.com/search"]
    }
  }
}
```

Any MCP client supporting Streamable HTTP can connect directly to `https://mcp.infobip.com/search` with no authentication required.

## MCP Servers

Infobip provides remote MCP servers that enable AI agents to send messages, run 2FA flows, manage contacts, and more. Each server is independent and product-specific. All servers support Streamable HTTP (default), SSE (append /sse to the URL), and STDIO via mcp-remote bridge. Authenticate with an API key header or OAuth 2.1.
